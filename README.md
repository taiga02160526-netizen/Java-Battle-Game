# Java Battle Game

Javaで制作したターン制の迷宮脱出RPGです。

## 概要
3階層の迷宮を探索し、敵との戦闘や宝箱、
装備・ショップ・レベルアップを通して
最終ボスの討伐を目指します。

## 使用技術
- Java
- Eclipse
- コマンドライン

## 主な機能
- 職業選択
- WASDによるマップ探索
- ランダムエンカウント
- 宝箱・装備・ショップ
- レベルアップ
- 最終ボス戦

## 実行方法
```bash
javac -encoding UTF-8 Battle.java
java -Dfile.encoding=UTF-8 Battle
